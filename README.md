# Bi Ne Bianni — Sitio web corporativo

Sitio web desarrollado para **Consultoría Social Bi Ne Bianni**, una empresa que trabaja con organizaciones e instituciones para fortalecer la relación entre sus proyectos y las comunidades donde se desarrollan.

La página presenta la empresa, su trayectoria y sus servicios relacionados con la gestión social, la sostenibilidad y el desarrollo territorial. También permite conocer sus proyectos y clientes, así como contactar con la consultoría mediante un formulario.
